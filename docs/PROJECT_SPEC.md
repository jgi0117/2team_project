# 프로젝트 정의 및 요구사항

출처: [프로젝트 개요 및 설계서 원본](프로젝트_개요_및_설계서_Kaggle반영.pdf). 아래 내용은 원본 설계서를 저장소 작업용으로 정리한 것이며, 완료된 분석 결과를 의미하지 않습니다.

## 목적과 범위

스마트 에너지·설비 예지보전 통합 프로젝트 (총 40시간).

전력·생산·기상 데이터로 에너지 사용과 수요를 분석하고, Kaggle AI4I 2020으로 설비 고장 위험을 분류합니다. 결과를 Plotly·Dash의 별도 화면 또는 탭으로 통합하여 에너지 관리와 예지보전 의사결정을 지원합니다.

두 데이터는 독립된 분석 트랙입니다. 에너지 데이터와 AI4I를 행 단위로 억지로 병합하지 않습니다.

## 필수 데이터

- 에너지: `integrated_energy_project.csv`, 제공 기상 데이터, 공공 전력 데이터.
- 공공 전력 데이터: 공공데이터포털 전력 데이터 또는 한국전력공사 지역별 전력판매량 중 한 가지 이상.
- 예지보전: Kaggle Predictive Maintenance Dataset (AI4I 2020) 필수 사용.
- 모든 데이터의 원 URL, 접근일, 라이선스, 파일명과 가공 과정은 `DATA_SOURCES.md`에 기록합니다.

## AI4I 예지보전

- `Machine failure`를 기본 타깃으로 사용합니다.
- `UDI`, `Product ID`는 식별자이며, 모델 입력에 사용하는지와 그 근거를 설명합니다.
- `Type`은 범주형으로 인코딩합니다.
- Air/Process temperature, Rotational speed, Torque, Tool wear를 주요 특성으로 검토합니다. 실제 컬럼 표기와 단위는 원본 데이터에서 확인합니다.
- `TWF`, `HDF`, `PWF`, `OSF`, `RNF`는 고장 원인을 직접 나타내므로 예측 시점 누수 가능성을 검토하고 기본 특성에서 제외하는 것을 원칙으로 합니다.
- 학습·시험 분할에 `stratify`를 적용하고 클래스 비율을 기록합니다.
- Decision Tree와 Random Forest를 포함하여 두 모델 이상을 비교합니다.
- 정확도뿐 아니라 Precision, Recall, F1, 혼동행렬, classification report를 함께 해석합니다.
- K-Means 군집화 또는 이에 준하는 비지도 이상 탐지를 수행합니다. 정상 군집과 이상 가능 군집의 특성 및 해석의 한계를 기록합니다.

## 에너지·시계열

- 공장·설비·기간별 전력사용량과 생산량을 집계하고 KPI를 정의합니다.
- 결측·중복·범위·자료형을 검사하고 처리 근거와 처리 전후 결과를 기록합니다.
- 회귀 모델을 기준 모델과 비교하고 MAE, RMSE, R-squared를 평가합니다.
- Prophet 시계열 예측은 시간 순서대로 학습·시험을 분리합니다.
- 실제값, 예측값, 예측 구간을 시각화합니다.
- 기상 변수는 예측 시점에 실제로 확보 가능한 값인지 설명합니다.

## 성공 기준

원본 설계서는 특정 모델 점수의 수치 목표를 제시하지 않습니다. 기준 모델 대비 비교, 누수 방지, 요구 분석의 수행, 필터·KPI의 일관된 갱신, 재현 가능한 실행 및 한계 설명을 검토합니다. 수치 목표는 데이터 확인 후 팀에서 정의하고 근거를 기록합니다.

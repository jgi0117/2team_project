# 수행 단계와 제출 체크리스트

원본 설계서의 40시간 프로젝트 수행 순서입니다. 단계별 시간과 팀원 담당은 아직 정하지 않았습니다.

| 단계 | 작업 | 검토 조건 | 주요 작업 위치 |
| --- | --- | --- | --- |
| 1 | 문제 정의·데이터 출처·성공 기준 | 두 데이터의 역할 구분 | docs/, DATA_SOURCES.md |
| 2 | 품질 검사·전처리·EDA | 처리 전후 결과와 근거 기록 | notebooks/, src/, data/processed/ |
| 3 | 에너지 회귀·Prophet 예측 | 시간 순서 분할, 기준 모델 비교 | src/energy/, notebooks/energy/ |
| 4 | AI4I 분류·이상 탐지 | 누수 방지, 불균형, Recall, 비지도 탐지 | src/maintenance/, notebooks/maintenance/ |
| 5 | Dash 통합·테스트 | 필터와 KPI의 일관된 갱신 | app/, tests/ |
| 6 | 최종 보고서·발표 | 결론, 한계, 재현성, 팀 기여 | reports/final/, presentations/ |

각 실험에는 데이터 버전, 전처리, 입력 특성, 타깃, 분할 방법, 랜덤 시드, 모델 설정, 평가지표, 기준 모델 비교, 한계, 실행 코드 경로를 남깁니다.

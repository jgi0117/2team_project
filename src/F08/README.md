# F08 · 담당자 및 조치 이력 관리

## 목적

부품별 연결 협력사/담당 연락처와 설비별 정비·조치 기록을 조회합니다. 이 기능은
기록을 조회하고 UI에서 메모를 남기는 보조 기능이며 자동 발주나 업무 시스템 전송은
수행하지 않습니다.

## 협력사 조회

`get_supplier(component, as_of)`는 부품 마스터의 `supplier_id`로 협력사 테이블을
조회합니다. 기준일 이하의 최신 예측 시점을 정한 뒤 해당 시점의 재고 스냅샷에서 부품별
가용 재고를 함께 반환합니다.

```python
from src.F08 import get_supplier

supplier = get_supplier("comp2", "2015-12-21")
```

응답은 부품 ID/가상 부품명, 협력사명, 담당 부서, 전화/이메일, 가용 재고, 표준 납기,
목표재고를 포함합니다. 협력사 데이터는 `data/operations/suppliers.csv` 및 부품 마스터를
사용합니다.

## 조치 이력 조회

```python
from src.F08 import get_history

history = get_history(machine_id=1, as_of="2015-12-21", limit=20)
```

기준 시점 이하의 `planned_at` 기록만 조회하고 최신 계획일 순으로 정렬합니다.
`delay_days = (completed_at - planned_at) / 86400초`로 완료 지연을 계산합니다. 완료되지
않은 기록은 완료 시각이 없으므로 지연 값도 결측으로 남습니다. `limit` 기본값은 20이며
`None`이면 제한 없이 반환합니다.

## UI 메모와 데이터 성격

UI는 기록을 페이지당 10건으로 보여주고, 사용자가 추가한 조치 메모는 브라우저의 로컬
저장소에 보관합니다. 이는 서버 DB나 운영 원본 CSV에 저장되는 것이 아니며 브라우저/기기
간 자동 동기화도 되지 않습니다.

현재 공급사 연락처는 합성 데이터입니다. 전화번호의 `XXXX`와 `example.invalid` 이메일은
실제 연락에 사용할 수 없습니다. 운영 발주에 앞서 실제 업체·담당자 정보로 교체해야 합니다.
가상 운영 기록은 현장 완료 실적이나 공급사 성과를 증명하지 않습니다.

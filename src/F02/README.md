# F02 · 부품 재고 및 조달 위험 계산

## 목적과 출력

각 설비·부품 예측 결과를 가상 운영 데이터의 재고·진행 주문·납기 기준에 연결해,
목표 정비일까지 부품을 준비할 수 있는지 판단합니다. `build_plan()`은 설비·부품별
정비/조달 계획 DataFrame을 반환하며 `build_procurement()`은 대시보드용 우선 목록,
부품 위험 집계, 발주 일정과 KPI를 묶어 반환합니다.

```python
from src.F02 import build_plan, build_procurement

plan = build_plan("2015-12-21")
overview = build_procurement("2015-12-21")
```

## 입력 데이터와 과거 시점 보호

- 예측은 `data/processed/predictions.csv`에서 조회 시점 이하의 가장 최신 배치를 씁니다.
- 부품별 기준은 `data/operations/part_master.csv`의 조달기간, 정비 준비기간,
	목표재고입니다.
- 재고, 진행 주문, 입고 예정일은 `operations_snapshot.snapshot()`으로 기준 시점까지의
	이벤트만 재생해 계산합니다. 미래 실제 입고·완료 정보는 과거 상태에 섞지 않습니다.
- 재고는 로트별 보유량에서 예약량을 뺀 뒤, 준비 완료·사용기한 이내·품질 상태
	`available`을 모두 만족하는 수량만 합산합니다.

## 설비·부품별 계산 순서

1. 부품별 계획 예측 기간은 `lead_time_days + preparation_days`입니다. 그 기간과 정확히
	 일치하는 예측 기간이 없으면 사용 가능한 기간 중 차이가 가장 작은 기간을 선택합니다.
2. 해당 부품의 설비 예측을 위험 점수 내림차순으로 정렬합니다. 가용재고 수량만큼
	 상위 설비에 1개씩 배정합니다.
3. 계획 정비일은 `예측 기준일 + 선택된 horizon_days`입니다.
4. 재고가 배정되면 준비 완료일은 기준일입니다. 재고가 없고 진행 주문이 있으면 가장
	 이른 예정 입고일과 기준일 중 늦은 날에 준비기간을 더합니다. 진행 주문이 없으면
	 기준일에 조달기간과 준비기간을 더합니다.
5. 대응 여유는 `계획 정비일 - 준비 완료일`을 날짜 단위로 계산합니다.
6. 발주 마감일은 `계획 정비일 - (조달기간 + 준비기간)`입니다.

| 상태 | 판정 규칙 | 의미 |
| --- | --- | --- |
| `covered` | 재고가 해당 설비에 배정됨 | 현재 재고로 대응 가능 |
| `watch` | 재고 없음, 대응 여유가 0일 이상, 발주 마감 전 | 마감 전 재고/발주 확인 필요 |
| `order_due` | 재고 없음, 발주 마감일이 기준일 이하, 여유는 음수가 아님 | 발주 진행 여부를 확인할 시점 |
| `late` | 준비 완료일이 계획 정비일보다 늦음 | 일정 회복 또는 긴급 조달 검토 |

계획 행에는 위험 점수, 재고, 예정 입고, 목표 정비일, 발주 마감일, 준비 완료 예정일,
대응 여유, 공급 출처, 권장 보충량이 들어갑니다. 권장 보충량은
`max(0, target_stock - 현재 가용재고)`이며 개별 계획 행마다 반복되는 부품 기준 수량입니다.

## 대시보드 집계

각 부품별 예측 설비 중 `ceil(설비 수 × 5%)`대를 점수 상위 후보로 뽑습니다. 후보는
`late > order_due > watch > covered` 상태 순, 같은 상태에서는 위험 점수 순으로
정렬합니다. 부품 위험 표는 후보 수, 부족 수량, 긴급 건수와 최대 점수 등을 요약합니다.
발주 마감 목록은 `late/order_due` 중 이번 주 종료일까지 마감이 도래하는 행입니다.

## 세부 이력 파일

대시보드 숫자의 시간별 변화를 확인할 때는 아래 파생 파일을 사용합니다. 두 파일은
운영 이벤트를 시점 순으로 재생한 결과이며 원본 CSV를 수정하지 않습니다.

- `data/processed/procurement_history.csv`: 발주 당시 재고·진행 주문·부족분, 예정/실제

- `data/processed/inventory_daily_history.csv`: 일자·부품별 입고/출고/폐기, 가용·격리
	재고, 진행 주문과 부족분.

## 해석 시 주의

운영 데이터는 실제 공장 실측이 아닌 합성 시나리오입니다. 설비는 부품 재고를 공유하는
중앙창고 정책으로 계산되며, 설비별 수요·실제 업체 실적을 뜻하지 않습니다. 계획 정비일은
예측 기간을 날짜로 변환한 값이지 보장된 고장일이 아닙니다. 재고가 없는 경우에도 계획을
완성하기 위해 공급 출처별 예상 준비일을 계산하며, 실제 납기 확약으로 읽어서는 안 됩니다.

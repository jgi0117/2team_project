# F07 · 최적 발주 시점 및 비용 분석

## 목적

F02의 설비·부품 계획 한 행을 기준으로 발주를 오늘 진행하거나 며칠 미루는 시나리오의
합성 비용을 비교합니다. 최저 비용이 되는 지연 일수를 `optimum`으로 돌려주지만,
입력 비용과 납기 가정에 의존하는 시뮬레이션이며 실제 최적 발주 권고와 같지는 않습니다.

## 계산에 쓰는 값

- 정비 목표일, 기준일, 위험 예측기간, 권장 보충량: F02 계획.
- 납기와 준비기간: `data/operations/part_master.csv`.
- 단가: `data/operations/costs.csv`의 구매, 발주 행정, 보유, 긴급 작업, 긴급 운송,
	정지 손실 항목.
- 계산 수량은 `max(1, recommended_quantity)`입니다. 권장 보충량이 0이어도 최소 한 개를
	비용 비교 단위로 둡니다.

## 비용 공식

각 지연 일수 d에 대해 준비 완료일은 `기준일 + d + 조달기간 + 준비기간`입니다.
목표 정비일과 준비 완료일의 날짜 차이를 `gap_days`로 놓습니다.

```text
holding_cost = max(0, gap_days) × 일일 보유비 × 수량
late_days = max(0, -gap_days)
disruption_cost = 0                                  (late_days = 0)
disruption_cost = 긴급 작업비 + 긴급 운송 할증 × 수량
									 + 일일 정지 손실 × late_days      (late_days > 0)
total_cost = 구매 단가 × 수량 + 발주 행정비
						 + holding_cost + disruption_cost
```

따라서 조기 발주는 준비 완료 후 목표일까지의 보유비를 늘리고, 늦은 발주는 긴급 작업,
긴급 운송과 지연 일수별 정지 손실을 더합니다. 폐기비와 예방 작업비는 이 `total_cost`
수식에 포함되지 않습니다.

## 가정과 한계

운영 데이터의 비용은 실제 시장 견적이 아니라 명시적 합성 가정입니다. 확률적 납기,
대체 공급사, 가격 변동, 현금흐름, 부품 사용기한에 따른 폐기, 예측 불확실성은 이 곡선에
반영되지 않습니다. 구매비는 모든 지연 시나리오에서 동일하게 포함되므로 비교를 지배하는
항목은 보유비와 지연 페널티입니다. 입력 단가를 바꾸면 최적 지연도 달라질 수 있습니다.

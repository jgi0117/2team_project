# F10 · 설비별 센서 이상 히트맵

## 목적과 입력

`outputs/model3/predictions.csv`에 저장된 Isolation Forest(IF) 설비별 결과를 한 대당 한
칸으로 표시합니다. 설비의 공정/라인 연결 정보가 없어 설비 단위로 제공하며, 고장 예측
위험을 표시하는 F09와는 다른 값입니다.

필요한 열은 `machineID, as_of, anomaly_score, threshold, is_anomaly`입니다. 로더는
키 결측/중복, 시간대가 있는 시각, 점수 범위 오류를 거부하고 다음 관계를 검사합니다.

```text
is_anomaly == (anomaly_score > threshold)
```

판정에 사용하는 임계값은 결과 행에 저장된 값입니다. 히트맵이 임계값을 새로 학습하거나
IF 점수를 고장 확률로 변환하지 않습니다.

## 공통 관측 시점 집계

`build_heatmap(data, as_of)`는 조회 마감 시점 이하의 가장 최근 `as_of`를 하나 고릅니다.
모든 설비에 이 공통 관측 시각만 적용합니다. 그 시각에 결과가 없는 설비는 회색으로
남고, 이전 시각 점수를 대신 가져오지 않습니다. 이 방식은 설비 간 서로 다른 날짜의
점수를 같은 순간의 값처럼 비교하는 일을 막습니다.

호버에는 IF 점수, 해당 행의 임계값, 경고/비경고, 원래 관측 시각을 표시합니다.
대시보드는 F09와 같은 기계 마스터 및 그리드 순서를 사용합니다. 점수 색상은 0~1 범위의
고정 스케일입니다.

## Python 사용

```python
from src.F10 import load_predictions, build_heatmap

data = load_predictions()
figure, metadata = build_heatmap(data, "2015-12-21")
```

`metadata`에는 설비 수, 결과가 존재하는 셀 수, 조회 기준일, 사용된 공통 관측 시각,
관측된 임계값 목록과 경고 설비 수가 들어갑니다. 기본 입력 경로는
`outputs/model3/predictions.csv`입니다.

## 해석 시 주의

IF 이상 점수는 학습된 IF 모델에서 센서 특징 조합이 이례적인 정도를 나타냅니다. 점수가
높다고 고장이 임박했거나 특정 센서가 원인이라는 뜻은 아닙니다. F09의 부품 고장 위험
점수와 단위가 다르므로 두 히트맵의 색을 수치적으로 비교·결합하지 마세요. 회색은
정상(0점)이 아니라 해당 공통 관측 시각의 결과가 없다는 뜻입니다.

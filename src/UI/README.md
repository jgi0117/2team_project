# 통계 화면 · 설비별 위험 히트맵

위쪽 F10은 설비별 센서 이상 위험, 아래쪽 F09는 설비별 고장 위험을 표시합니다. 각각 100대 설비를 20열 × 5행에 배치하며 두 히트맵의 설비 위치가 같습니다.

각 영역의 한 줄 머리글에 제목·위험의 의미·낮음→높음 색상 범례·날짜를 표시합니다. 바로 아래 히트맵이 남은 공간을 채웁니다. 필터나 내부 스크롤은 없고 상세 정보는 호버로 확인합니다.

```powershell
.\.venv\Scripts\python.exe -m src.UI.app
```

접속: `http://127.0.0.1:8050`

- `src/F09`: 부품 위험 최댓값으로 요약한 설비별 고장 위험.
- `src/F10`: 저장된 IF 결과를 사용하는 설비별 이상 위험.
- `src/common/machine_heatmap.py`: 설비 한 대당 한 칸으로 표시하는 공통 그래프.
- `statistics.py`: F10·F09 배치.
- `heatmap_panel.py`: 두 영역이 함께 사용하는 한 줄 머리글과 그래프 영역.
- `assets/heatmap-dashboard.css`: 화면 높이에 맞춘 두 히트맵 레이아웃. 이전 스타일 캐시와 구분하기 위해 새 파일명을 사용합니다.

F02·F06은 제거한 상태를 유지합니다.

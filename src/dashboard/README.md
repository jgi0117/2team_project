# 메인 대시보드

## 작업 범위

기획서 5쪽의 분석·경고·기한 KPI, 우선 점검 To-Do, 고장 위험 캘린더, 과거 대응률을 표시합니다.

## 입출력

- 입력: predictions.csv, maintenance_plan.csv, statistics.csv
- 출력: 메인 화면과 설비 상세 이동

## 공통 규칙

판단 로직을 화면에서 다시 계산하지 않습니다. 원본 데이터의 조회 기준시점을 표시하며 예시 화면의 2026년·건수는 실제 관측 결과로 사용하지 않습니다.

[공통 데이터 계약](../../docs/DATA_CONTRACT.md)을 따릅니다. 담당자는 팀에서 정하고 본인 브랜치에서 이 디렉토리를 중심으로 작업합니다. 현재는 개발 구조만 준비한 상태입니다.

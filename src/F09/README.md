# F09 · 설비별 고장 위험 히트맵

## 표시 내용과 집계

설비 한 대를 한 칸으로 표시합니다. 기본 설비 목록은 PdM 기계 마스터를 읽어 고정된
그리드에 배치합니다(100대 데이터는 20열 × 5행). F10과 같은 설비 순서를 사용해 두
히트맵의 위치를 비교할 수 있습니다.

선택한 기준일·예측기간·모델 버전의 각 설비에 대해 comp1~comp4 예측을 모읍니다.

```text
설비 표시 점수 = max(comp1 점수, comp2 점수, comp3 점수, comp4 점수)
```

네 부품 점수가 모두 존재해야 표시 점수를 확정합니다. 하나라도 결측이면 0으로 채우지
않고 해당 설비 칸을 회색으로 표시합니다. 호버에는 최대 위험 부품, 각 부품 점수와
기준일/기간을 보여줍니다.

## Dash에서의 기준 선택

통계 화면은 `UI_AS_OF`와 가장 최신 모델 버전을 기준으로 삼습니다. 선택 가능한 기간은
7, 14, 42일이며, 7일이 있으면 기본 선택합니다. 목적 표시는 7일 즉시 대응, 14일 단기
정비계획, 42일 장기 조달계획 참고용입니다. 실제 데이터에서 사용할 수 없는 기간은
선택지에 나오지 않습니다.

## 독립 HTML 생성

```powershell
python -m src.F09 --as-of 2015-12-21 --horizon 28 --output outputs/F09/heatmap.html
```

생성기는 `data/processed/predictions.csv`를 사용합니다. `--as-of` 생략 시 파일의 최신
날짜, `--version` 생략 시 정렬상 가장 뒤인 모델 버전, `--horizon` 생략 시 28일을
사용합니다. 지정 조건의 결과가 없으면 빈 점수를 임의 대체하지 않습니다. HTML은 기본
`outputs/F09/heatmap.html`에 저장됩니다.

Dash 실행은 프로젝트 루트에서 다음과 같습니다.

```powershell
python -m src.ui.app
```

Python에서는 `load_predictions()`와 `build_heatmap(data, as_of, horizon_days,
model_version, machines=...)`를 이용할 수 있습니다. 반환값은 Plotly Figure와 표시 가능한
셀 수, 데이터 출처, 보정 여부 등의 메타데이터입니다.

## 색상 및 해석 주의

색상 범위는 점수 0~1에 고정되어 있어 날짜별 상대 순위가 아니라 절대 입력 점수에 따라
매핑됩니다. 보정된 점수만 확률로 부를 수 있으며 현재 데이터처럼 미보정이면 위험 점수로
해석해야 합니다. 부품별 최댓값은 보수적인 화면 집계일 뿐 설비 전체 고장 확률, 설비 간
부품 수요 합계 또는 정확한 고장일이 아닙니다.

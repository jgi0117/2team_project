# F09 설비별 고장 위험

설비 한 대를 한 칸으로 표시합니다. 100대를 20열 × 5행에 배치하고 번호와 위험 색상만 표시합니다. F10에서도 설비 번호의 위치가 동일합니다.

- 각 설비의 점수는 동일한 기준일·예측기간에서 **4개 부품 위험 점수의 최댓값**입니다. 설비 전체의 고장 확률로 해석하지 않습니다.
- 현재 예측 결과는 확률 보정 전입니다. 색상은 점수 0~1에 고정합니다.
- 부품 중 하나라도 예측이 없으면 설비 점수를 회색으로 표시합니다. 일부 부품만으로 낮은 점수를 확정하지 않습니다.
- 호버에서 최대 위험 부품과 부품별 점수를 확인합니다. 화면 본문에는 부품을 나누어 표시하지 않습니다.
- 최신 예측일의 28일 결과를 기본 사용합니다. 28일 결과가 없으면 해당 모델의 가장 긴 예측기간을 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m src.UI.app
```

독립 HTML 출력:

```powershell
.\.venv\Scripts\python.exe -m src.F09 --as-of 2015-12-21 --horizon 28
```

# 발주·정비 계획

## 작업 범위

부품별 조달기간과 가용재고, 입고 일정, 사용 기한, 정비 준비시간을 반영해 대응 여유와 권장 조치를 계산합니다.

## 입출력

- 입력: predictions.csv 및 data/operations/ 운영 데이터
- 출력: data/processed/maintenance_plan.csv

## 공통 규칙

기한 초과·예약·격리 재고를 제외하고 투입 시점까지 유효한 로트를 배정합니다. 진행 주문을 고려해 중복 발주를 막습니다. 비용 비교를 수행할 경우 별도 costs.csv의 가정과 단위를 기록합니다.

[공통 데이터 계약](../../docs/DATA_CONTRACT.md)을 따릅니다. 담당자는 팀에서 정하고 본인 브랜치에서 이 디렉토리를 중심으로 작업합니다.

## 구현한 기능

`operations_snapshot.snapshot("2015-06-01 06:00:00")`으로 당시까지 알려진 가상 주문·재고·정비 결과를 조회합니다. 최종시점 CSV를 과거 판단에 바로 조인하지 않습니다. 가용 수량은 준비 완료·유효기한·품질 조건을 확인한 `quantity_available`을 사용합니다. 선예약 없는 기준 정책이므로 예약량은 0입니다. 예측 결과에 따른 정비·발주 최적화는 아직 구현하지 않았습니다.

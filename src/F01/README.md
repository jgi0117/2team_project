# F01 · 설비 이상 및 고장 위험 탐지

## 목적

고장 예측 결과와 별도 Isolation Forest(IF) 경고를 모아 현재 확인이 필요한 설비를
찾습니다. 공개 함수는 `src/maintenance_planning.service.dashboard_overview()`의
계산 결과 중 설비 경고와 전일 대비 급상승 항목을 반환합니다.

## 입력과 기준 시점

- 고장 예측: `data/processed/predictions.csv`의 설비·부품별 `failure_probability`,
	`as_of`, `horizon_days`, `model_version`, `calibrated`.
- IF 결과: `outputs/model3/predictions.csv`의 설비별 `is_anomaly`.
- `as_of`를 주면 그 날짜/시각 이하에서 가장 최근 예측 배치를 선택합니다. 생략하면
	파일의 가장 최신 예측 시점을 씁니다. 같은 배치 안에서 모델 버전은 정렬상 가장
	뒤에 오는 값을 선택합니다.

## 계산 규칙

### 설비 경고 목록

1. 선택된 예측 배치에서 설비별 위험값을 `max(failure_probability)`로 집계합니다.
	 이 경고 집계는 배치에 존재하는 부품·예측기간 점수를 설비별로 합치는 규칙이며,
	 F09의 지정 예측기간 히트맵과 목적이 다릅니다.
2. 모든 점수가 보정된 배치라면 점수가 0.5 이상인 설비를 예측 경고로 지정합니다.
	 미보정 배치라면 설비 점수의 95백분위수를 경계로 그 이상인 설비를 지정합니다.
3. 예측 경고 집합과 기준 시점 이전에 확인된 가장 최근 IF 경고 설비 집합을 합집합으로
	 묶습니다. 중복 설비는 한 번만 셉니다.

### 전일 대비 위험 급상승 TOP 3

중간 산출물 `data/processed/_work/pred_ml.parquet`가 있을 때만 계산합니다. 7일
예측에서 당일·전일 모두 존재하는 설비의 점수를 비교하고, 당일 설비별 최대값이 전체
설비 점수의 상위 5% 경계 이상이며 점수가 오른 경우만 남깁니다.

`변화량 = 당일 설비 점수 - 전일 설비 점수`

변화량 내림차순 상위 3대가 `surges`입니다. 두 날짜 결과가 모두 없거나 파일이 없으면
빈 목록을 반환합니다. 이 변화량은 미보정 점수 변화이며 확률 증가율이 아닙니다.

## 사용법

```python
from src.F01 import build_detection

result = build_detection("2015-12-21")
print(result["warning_machine_ids"])
print(result["surges"])
```

`as_of=None`이면 데이터의 최신 예측 시점을 기준으로 합니다. 결과에는 기준일,
직전 기준일, 모델 버전, 보정 여부, 위험 급상승 목록, IF 최신 지도, 경고 정책,
경고 설비 ID와 KPI의 경고 설비 수가 포함됩니다.

## 해석 시 주의

- 미보정 `failure_probability`는 모델 점수입니다. 퍼센트 확률처럼 읽으면 안 됩니다.
- IF 점수는 센서 패턴 이상 신호이고 고장 확률이 아닙니다. 두 점수를 더하거나 평균내지
	않습니다.
- 경고 경계는 운영 확인용 규칙입니다. 0.5 또는 상위 5%가 실제 비용·고장률로 검증된
	최적 임계값이라는 뜻은 아닙니다.
- 이 기능은 설비 상태를 자동 판정하거나 고장 날짜를 산출하지 않습니다.

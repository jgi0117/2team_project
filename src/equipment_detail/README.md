# 설비 상세

## 작업 범위

기획서 6쪽의 선택 설비 및 comp1~comp4 상태, 조달기간·재고·대응 여유, 정비 기록을 표시합니다.

## 입출력

- 입력: 설비·부품 선택값, predictions.csv, maintenance_plan.csv, maintenance_records.csv
- 출력: 설비 상세 화면과 정비 기록 입력·조회

## 공통 규칙

정상·위험 표시의 확률 의미와 기준 기간을 통일합니다. 기록 입력은 원본 PdM_maint.csv를 덮어쓰지 않고 별도 운영 데이터에 저장합니다.

[공통 데이터 계약](../../docs/DATA_CONTRACT.md)을 따릅니다. 담당자는 팀에서 정하고 본인 브랜치에서 이 디렉토리를 중심으로 작업합니다. 현재는 개발 구조만 준비한 상태입니다.

# 설비·부품 통계

## 작업 범위

기획서 7쪽의 설비·부품별 고장·교체·경고·대응 현황과 기간별 추이를 집계합니다.

## 입출력

- 입력: 원본 이벤트, 예측 결과, 정비 계획, 운영 정비 기록
- 출력: data/processed/statistics.csv 및 통계 화면

## 공통 규칙

고장 행 수와 설비 수를 구분하고 대응률의 분모·분자·평가기간을 명시합니다. 기획서의 자동차 브랜드 예시를 실제 설비 데이터로 사용하지 않습니다.

[공통 데이터 계약](../../docs/DATA_CONTRACT.md)을 따릅니다. 담당자는 팀에서 정하고 본인 브랜치에서 이 디렉토리를 중심으로 작업합니다. 현재는 개발 구조만 준비한 상태입니다.

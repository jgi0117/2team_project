# 부품별 고장예측

## 작업 범위

comp1~comp4의 기간별 고장 위험 학습·추론·시간순 평가를 담당합니다.

## 입출력

- 입력: features.csv, labels.csv
- 출력: data/processed/predictions.csv, model_metrics.csv

## 공통 규칙

예측기간과 경고 기준은 검증 구간에서 선택하고 별도 테스트 구간에서 평가합니다. 정확한 고장 시각은 검증한 시점 추정 모델이 있을 때만 제공합니다.

[공통 데이터 계약](../../docs/DATA_CONTRACT.md)을 따릅니다. 담당자는 팀에서 정하고 본인 브랜치에서 이 디렉토리를 중심으로 작업합니다. 현재는 개발 구조만 준비한 상태입니다.

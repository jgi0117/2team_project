# 설비 고장 예측 기반 정비 의사결정 지원 시스템

2조 프로젝트. 고장을 미리 예측해 부품 조달과 정비에 필요한 시간을 확보하고, 설비보전 담당자의 점검·발주·정비 시점 결정을 지원합니다.

## 브랜치 안내

`main`은 프로젝트 안내용 브랜치이며 **README.md만 관리**합니다. 소스, 데이터와 기획서는 아래 작업 브랜치에서 확인합니다.

| 작업 브랜치 | 내용 |
| --- | --- |
| [GJ](https://github.com/jgi0117/2team_project/tree/GJ) | 공통 프로젝트 구조, 데이터, 기능별 개발 |
| [GE](https://github.com/jgi0117/2team_project/tree/GE) | 공통 프로젝트 구조, 데이터, 기능별 개발 |
| [JH](https://github.com/jgi0117/2team_project/tree/JH) | 공통 프로젝트 구조, 데이터, 기능별 개발 |

세 작업 브랜치는 같은 초기 구조에서 시작합니다. 각자 본인 브랜치에서 담당 `src/` 디렉토리를 수정하고, 담당 기능은 팀에서 배정합니다. `main`에 코드·데이터를 병합하지 않고 안내 문서만 유지합니다.

## 기획 범위

- Azure PdM 센서·오류·교체·고장 이력으로 설비와 부품의 위험을 분석합니다.
- 부품 조달기간, 가용재고, 입고일과 사용 기한을 함께 고려해 대응 시점을 판단합니다.
- 메인 대시보드, 설비 상세, 설비·부품 통계 화면을 구성합니다.

기준 기획서는 각 작업 브랜치의 `docs/2조_프로젝트_기획서.pdf`입니다. 현재는 기능별 개발 구조와 원본 데이터를 준비한 단계이며 실행 앱과 학습 모델은 아직 없습니다.

# Dash 앱 작업 위치

이 디렉토리는 아직 실행 가능한 앱을 포함하지 않습니다.

- `pages/`: 설비 현황, Azure PdM 고장예측, 조달·정비 비용 비교, 데이터 조회, 보고서 요약 화면.
- `components/`: 기간·설비·예측기간 필터, KPI 카드, 표와 그래프 등 공통 UI.
- `assets/`: CSS와 이미지.

분석 로직은 `src/`에 구현하고, 앱은 고장예측과 비용 시뮬레이션 결과를 읽어 표시합니다. CSV 업로드·검증, DataTable, 필터, 결과 다운로드를 구현하며 필터 변경 시 KPI와 그래프가 일관되게 갱신되는지 검증합니다.

앱 진입점을 구현한 뒤 루트 README에 실제 실행 명령을 추가합니다.
